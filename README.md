# Evaluación N°3 – Programación Web

Felipe Álvarez Valle

Aplicación web en Flask con un menú y dos ejercicios:

- **Ejercicio 1:** promedio de 3 notas (10 a 70) y asistencia (0 a 100). Muestra APROBADO si el promedio es 40 o más y la asistencia es 75 % o más; si no, REPROBADO.
- **Ejercicio 2:** de 3 nombres distintos, muestra el que tiene más caracteres y cuántos tiene.

## Cómo ejecutarlo

```
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

Luego abrir http://127.0.0.1:5000
